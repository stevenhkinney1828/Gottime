Rather than guess a third time, shipped a build with on-screen diagnostics instead of a crash, which gave a definitive, unambiguous answer: **custom `INFOPLIST_KEY_*` settings never synthesize into this project's compiled Info.plist at all** — only real, Apple-defined keys do (contradicting general web research, overridden by direct evidence from the actual binary).
